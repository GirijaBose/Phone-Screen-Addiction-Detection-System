# Phone-Screen-Addiction-Detection-System
MindGuard AI is an AI-based Digital Wellness Platform developed to detect smartphone addiction and monitor digital eye strain.

## Features
- Smartphone addiction detection
- Eye strain analysis using webcam
- AI wellness coach
- Digital detox suggestions
- Usage pattern analysis
- Facial and visual scan

## Technologies Used
- Python
- Streamlit
- Machine Learning
- OpenCV
- MediaPipe
- Pandas
- NumPy
- Groq API

## Modules
1. Addiction Detection
2. Eye Strain Detection
3. AI Wellness Coach
4. Visual Scan
5. Digital Detox Plan

## How to Run the Project

1. Install required libraries:
pip install -r requirements.txt

2. Run the application:
streamlit run app.py

## Project Outcome
This project helps users analyse smartphone usage behaviour and promotes healthy digital habits using AI technologies.
